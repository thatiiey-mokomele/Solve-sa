SOLVE SA starter prototype

This is an early front-end demo, not a live service.
- Open index.html in a browser to preview.
- For PWA installation, it must be hosted over HTTPS (or run on localhost).
- Forms save demo data only in the same browser/device using localStorage.
- No data is sent to a server.
- Do not collect sensitive personal information in this prototype.
- Before public launch: add secure authentication, database, moderation,
  verified listings, privacy notice/POPIA review, reporting and abuse controls.

Next development step: choose and set up a secure hosting + database service.
